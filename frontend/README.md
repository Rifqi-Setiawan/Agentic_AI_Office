# Agentic AI Office v2 — Frontend

Aplikasi single-page berbasis Vite, React 18, PixiJS v8, TypeScript, dan Tailwind CSS untuk antarmuka world isometrik 2.5D dan HUD real-time.

## Standar Kode & CI
- **Linting**: `npm run lint` (`eslint .`)
- **Type Checking**: `npm run typecheck` (`tsc --noEmit`)
- **Testing**: `npm run test` (`vitest run`)

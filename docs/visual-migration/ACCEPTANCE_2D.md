# Acceptance aktif — pemulihan desain Z08

Instruksi ini mengganti syarat Blender/native render/kuota frame lama. Semua kontrak layout, roster/persona, navigasi, telemetry, fungsi, audio, suasana, vitals/collective, Founder controls dan redaction tetap berlaku.

- Referensi: bandingkan gambar meja/karakter user; gambar kantor utama masih belum ditemukan pada path yang tersedia. Baseline screenshot, concept art dan candidate source harus dilabeli berbeda.
- Asset: clean 2D outlines/cel shading, light oak/charcoal/cyan; alpha diperiksa pada latar terang/gelap; crop tidak membawa sprite tetangga; bentuk badan tidak diregangkan; foot anchor/arah/skala konstan.
- Arah: SE/SW/NE/NW benar, tidak menggunakan mirror yang menggeser aksesori.
- Motion: idle ke walk ke seated/typing terbaca. Langkah kaki benar-benar digambar; satu kaki berpijak, kedua kaki bergantian, loop tidak tersentak. Dua pose langkah saat ini belum lulus syarat ini.
- Geometry: empat workstation, dua standing desk, enam slot dan tiga pintu Z08; koridor tetap terbuka; occlusion front/back dan posisi duduk harus dinilai di browser.
- Data: task/badge berasal dari status asli. Fixture lokal berlabel. Aksi yang belum dikonversi tetap tersedia, status baseline dicatat.
- Browser: overview, dekat Z08 pada ukuran normal, pendekatan pintu, duduk/kerja, pan/zoom, mobile, day/night dan console. Video motion jika akses browser tersedia. Tool denial tidak diakali.
- Evidence: screenshot/video browser hanya bila benar-benar dieksekusi. Offline layer composition dan contact sheet merupakan bukti asset check saja.
- Checkpoint: perbaiki cacat jelas, laporkan aset/integrasi/QA/blocker terpisah; USER STYLE APPROVAL diperlukan sebelum batch zona lain.
- Lokal saja: tidak push/merge/deploy, VPS/gateway untouched. Full migration belum selesai saat hanya slice tersedia.

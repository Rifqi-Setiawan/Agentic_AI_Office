# Aset Sumber 3D (Quaternius & Kenney)

Folder ini menyimpan model 3D GLB pihak ketiga berlisensi CC0 (Public Domain) yang digunakan sebagai input ke pipeline render sprite isometrik 2.5D.

## Struktur Folder
- `characters/`: Model humanoid GLB Quaternius (3 karakter: `figure_Casual.glb`, `figure_Worker.glb`, `figure_Suit.glb`).
- `furniture/`: Model furnitur dan peralatan kantor GLB Kenney Furniture Kit (140 model).

## Lisensi
Semua aset di folder ini berlisensi **CC0 1.0 Universal (Public Domain Dedication)**:
- Kenney Furniture Kit: https://kenney.nl/assets/furniture-kit
- Quaternius Animated Men: https://quaternius.com/packs/animatedmen.html

Lihat rincian lisensi lengkap di file `LICENSES.md` pada root repository.

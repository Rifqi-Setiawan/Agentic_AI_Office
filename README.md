## 🏛️ Campus Architecture & Departmental Zones

The campus is structured into specialized departments representing real engineering capabilities:
1. **Central Innovation Plaza:** Live GitHub Telemetry board displaying recent production repositories.
2. **Command Pavilion (Jarvis):** Multi-agent coordination and high-level routing headquarters.
3. **AI Research Sanctum (Oracle):** Deep reasoning research and enterprise data intelligence lab.
4. **Systems Architecture Citadel (Daedalus):** Scalable Lakehouse and distributed systems blueprint center.
5. **Software Engineering Forge (Forge & Nova):** High-throughput Python FastAPI, DuckDB, and PostgreSQL microservices.
6. **UI/UX & Product Design Atelier (Prism & Muse):** Interactive frontends, 3D graphics, and anti-slop design.
7. **QA & Security Citadel (Sentinel & Bastion):** Strict independent verification, API regression, and SRE uptime monitoring.
8. **Data Lakehouse Terminal (Vector):** Medallion data pipeline hub (Bronze ZSTD -> Silver SCD2 -> dbt Gold Star Schema).
9. **Knowledge Sanctuary & Academy (Merlin):** Technical learning nooks, official certifications, and academic research.
10. **Campus Coffee Lounge:** Relaxed discussion bar for architecture reviews.

## ⚡ Tech Stack & Engineering Highlights

* **Frontend Engine:** Vite 5 + React 18 + Three.js (`@react-three/fiber` & `@react-three/drei`).
* **Styling & UI:** Tailwind CSS + retro pixel typography (`Pixelify Sans`, `Press Start 2P`).
* **Zero Asset Bloat:**
  * 100% procedural 16×16 pixel textures drawn at runtime via Canvas 2D API (`textures.js`).
  * Procedural synthesizer background ambient audio and sound effects via native Web Audio API (`sound.js`) with zero static audio files.
  * Ultra-lightweight production bundle (<1.3 MB total, ~350 KB gzipped) loading in <500ms.
* **Autonomous Locomotion:** Real-time **A\*** pathfinding algorithm with dynamic collision avoidance and waypoints.
* **Live Telemetry:** Automatic asynchronous ingestion of recent GitHub repositories and live production deployments.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Rifqi-Setiawan/Agentic_AI_Office.git
cd Agentic_AI_Office

# Install dependencies
npm install

# Start local development server (http://localhost:5173)
npm run dev

# Build production bundle (dist/)
npm run build
```
